# BOT FAC RP

## Instalação

1. Instale o Node.js
2. Abra a pasta do bot
3. Abra o terminal na pasta
4. Rode:

npm install

5. Depois edite o arquivo `index.js` e coloque:

- TOKEN do bot
- ID do servidor
- ID dos canais
- ID do cargo staff

6. Para iniciar:

node index.js

## Funções

- Sistema de solicitar set
- Ticket automático
- Comando /parceria
- Embed automática
- Ping da staff
